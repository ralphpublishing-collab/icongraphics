# ICON GRAPHICS architecture

This is a React 19 / TypeScript site using TanStack Start file routes, Vite and the Netlify adapter. Global styles live in `src/styles.css`; the root shell and base brand metadata live in `src/routes/__root.tsx`. Each page route defines its own metadata and canonical URL. TanStack generates `src/routeTree.gen.ts`; do not edit it manually.

`src/components/MarketingPage.tsx` contains the shared layout, original logo, navigation, footer, WhatsApp integration, accessible portfolio artwork, and page/section components. `EnquiryForm.tsx` owns real Netlify submissions. `NotFoundPage.tsx` is the shared missing-page fallback. `src/routes/portfolio_.$projectId.tsx` deliberately opts out of the portfolio list parent, and validates project ids in a loader with `notFound()`.

`src/data/site.ts` is the central source of official services, portfolio entries, FAQ content, social links, testimonials and catalogue URL. Keep all nine official service names and descriptions accurate. Use the official brand identity, email and WhatsApp number. Do not invent clients, testimonials, awards, employees, qualifications, pricing or historical achievements. New portfolio items use a service id for category and optional image, video and audio paths in `public/portfolio/`. Preserve concept labels for demonstration work and remove them only when genuine project content replaces it. Keep a preview in every service category while real work is unavailable.

Uploaded source assets are preserved in `public/img/`; never redesign or recolour the original logo or generate a replacement founder portrait. The logo is intentionally displayed against its original black background. Use Netlify Image CDN for raster media, preserving aspect ratio. Mockups are code-native illustrative concept art, not completed client projects.

The design uses clean white, charcoal and restrained cyan accents derived from the original multicoloured logo, Manrope headings and DM Sans body type. Alternate light/dark sections, retain generous spacing, and collapse split layouts on mobile. Maintain keyboard focus, labelled form fields, reduced-motion support and honest placeholders. No decorative buttons without actions.

Contact and quote share `project-enquiry`. Every submitted field must match `public/__forms.html`. Always POST to the static registration path, not `/`, because SSR intercepts root POSTs. Keep the honeypot, consent, response status checks, timeout and registration marker detection. The `.netlify/features/netlify-forms` marker requests form detection on deployment. Do not replace real submissions with simulated success. Use Netlify platform storage if additional persistent features are introduced.

`netlify.toml` publishes `dist/client`; the adapter handles server routing. Do not add a wildcard SPA rewrite. Security headers restrict framing and device permissions without blocking forms or Image CDN. Intended canonical domain is icongraphics.com.ng; no domain connection is implied. Update the static sitemap as pages/projects change. Privacy and terms deliberately mark owner confirmation items.

Use existing dependencies. Keep changes focused and update this document if architecture changes. Read applicable Netlify skills before feature work. Follow current run instructions on whether local builds/tests/dev servers are permitted; this generation leaves validation to the platform. No secrets belong in client code, files or logs.

`src/components/UpgradePages.tsx` owns quotation-based pricing, the Insights index and guides, and refund/cancellation and delivery policies. `src/data/insights.ts` contains repository-authored editorial guides and topics, without fabricated founder bylines. Extend the sitemap for new guides. Pricing fields in `src/data/site.ts` remain null until approved prices are supplied. Project records support objectives, direction, execution, deliverables and labels for honest case studies.

The enquiry form uses multipart FormData for one optional reference attachment, validated to PDF/JPEG/PNG/WebP under 5 MB, and joins additional service choices into one registered field. Keep all brief fields registered. `src/lib/analytics.ts` emits integration events only; do not add analytics network requests or identifiers without a consent-aware integration. Supplied reference originals remain in `public/img/`; `logo-reference.png` and `rapheal-adebayo-supplied.jpeg` are the current display sources.
